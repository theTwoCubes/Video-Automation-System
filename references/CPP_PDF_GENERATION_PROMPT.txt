==========================================================
LATEX COMPILATION RULES & FEW-SHOT EXAMPLE (CRITICAL)
==========================================================

You are generating raw LaTeX code. It MUST compile flawlessly on the first try.
LLMs frequently break LaTeX compilation by forgetting to escape special characters. 
You MUST obey these rules:

1. **Escape Special Characters in Normal Text**: You must escape `&`, `%`, `$`, `#`, and `_`.
   - WRONG: Pointers & References
   - RIGHT: Pointers \& References
   - WRONG: 100% efficiency
   - RIGHT: 100\% efficiency

2. **Inline Code & Underscores**: Never leave raw underscores in normal text. E.g., do NOT write `std::unique_ptr`. ALWAYS wrap inline code in the provided macros: `\cpp{std::unique_ptr}`, `\stdtype{std::vector}`, `\header{<iostream>}`, `\keyword{const}`.

3. **Code Blocks (cppcode)**: Inside the `\begin{cppcode}` ... `\end{cppcode}` environment, you are in verbatim mode. Do NOT escape characters inside code blocks.

**FEW-SHOT EXAMPLE OF EXPECTED FORMATTING:**
```latex
\section{Pointers \& References}

Memory management is 100\% critical in C++. Let's look at \cpp{std::unique_ptr} and the \header{<memory>} header. 
Notice how the ampersand (\&) and percent (\%) signs are escaped, and how the underscore in \cpp{std::unique_ptr} is safely wrapped inside the \cpp{} macro!

\begin{cppcode}
#include <memory>
// Inside this code block, do NOT escape anything! 
// & and % and _ are totally safe here.
int main() {
    std::unique_ptr<int> ptr = std::make_unique<int>(10);
    return 0;
}
\end{cppcode}
```
