==========================================================
LATEX COMPILATION RULES & FEW-SHOT EXAMPLE (CRITICAL)
==========================================================

You are generating raw LaTeX code. It MUST compile flawlessly on the first try.
LLMs frequently break LaTeX compilation by forgetting to escape special characters.
You MUST obey these rules:

1. **Escape Special Characters in Normal Text**: You must escape `&`, `%`, `$`, `#`, and `_`.
   - WRONG: args & kwargs
   - RIGHT: args \& kwargs
   - WRONG: 100% pure
   - RIGHT: 100\% pure

2. **Inline Code & Underscores**: Never leave raw underscores in normal text. E.g., do NOT write `__init__`. ALWAYS wrap inline code in the provided macros: `\py{__init__}`, `\pytype{list}`, `\pymod{os.path}`, `\keyword{yield}`.

3. **Code Blocks (pycode)**: Inside the `\begin{pycode}` ... `\end{pycode}` environment, you are in verbatim mode. Do NOT escape characters inside code blocks.

**FEW-SHOT EXAMPLE OF EXPECTED FORMATTING:**
```latex
\section{Args \& Kwargs}

Python functions accept 100\% flexible argument lists through \py{*args} and \py{**kwargs}.
The \pymod{functools} module provides \py{functools.wraps} to preserve the wrapped function's \py{__name__} and \py{__doc__} attributes.
Notice how the ampersand (\&) and percent (\%) signs are escaped, and underscores in \py{__name__} are safely wrapped inside the \py{} macro!

\begin{pycode}
from functools import wraps

def my_decorator(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper
\end{pycode}
```
